# DACHWERK Foto-Zeichner V4

1. `index.html` im Browser öffnen oder den Inhalt in den GitHub-Pages-Ordner hochladen.
2. Foto wählen und warten, bis es im großen Feld erscheint.
3. „Zollstock markieren“ drücken und zwei Punkte auf dem Zollstock antippen.
4. Abstand zwischen den beiden Punkten in cm eintragen.
5. „Schrankkontur markieren“ drücken und mindestens drei Schrank-Ecken der Reihe nach antippen.
6. „Kontur schließen“ und danach „Zeichnung erstellen“.

Die Zeichnung ist eine manuell markierte Kontur; keine automatische Objekterkennung oder Perspektivkorrektur. Maße sind Schätzungen.
